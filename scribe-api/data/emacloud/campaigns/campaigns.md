# Email Campaigns

Build and launch bulk email marketing campaigns using EmaCloud.

## Steps

1. Select your subscriber contact list.
2. Choose a pre-built template or use the drag-and-drop builder.
3. Configure subject lines and sender profiles.
4. Preview, send a test email, or schedule delivery.
